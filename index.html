🖥️ Computer Issues Quick Start Guide

Identify and solve hardware, software, and printer problems

Hardware-Related Issues

Hardware faults occur in the physical components of the computer such as the CPU, RAM, motherboard, graphics card and power supply. These faults often show clear symptoms that help identify the failing component.

📢 POST Beep Codes (AWARD BIOS)

When the computer starts, the BIOS performs a Power-On Self-Test (POST). If a component fails, the motherboard plays beep codes to indicate the fault.

1 short beep – System boot successful. No action required.
2 short beeps – CMOS settings error. Enter BIOS and reset CMOS to default settings.
1 long, 1 short – Memory or motherboard error. Reseat RAM, test one stick at a time, replace faulty RAM or motherboard.
1 long, 2 short – Monitor or graphics card error. Reconnect monitor, reseat graphics card, replace if needed.
1 long, 3 short – Keyboard error. Reconnect keyboard, try another USB port, replace keyboard.
1 long, 9 short – BIOS ROM error. BIOS is corrupted. Reflash or reinstall BIOS.
Continuous long beeps – Graphics card not inserted properly. Reseat graphics card firmly in PCI-E slot.
Continuous short beeps – Power error. Disconnect all hardware, reconnect CPU, motherboard and GPU only, then reconnect components one by one. Replace PSU if issue continues.
Note: Passing POST only confirms basic functionality. Hardware may still fail under load due to heat or driver issues.
🌡️ Excessive Heat

Problem: Excessive heat causes random restarts or shutdowns, especially during high processing loads. Heat issues occur due to high room temperature, dust buildup, inadequate cooling or failing fans.

Diagnosis: Check temperatures in BIOS or use hardware monitoring software. Stress the CPU or GPU and observe if the system restarts at a specific temperature.

Solutions:

  • Clean dust from components
  • Add more case fans
  • Upgrade CPU or GPU coolers
  • Improve airflow and ensure vents are not blocked
🔊 Noise Issues

Problem: Loud noise usually comes from worn-out cooling fans spinning at high RPM.

Solutions:

  • Replace old fans with larger, higher-quality ones that move more air at lower RPM
  • Clean dust from components
  • Ensure cables are not touching fan blades
👁️ Physical Inspection

What to Check:

  • Monitors for dead pixels or cracks
  • Keyboards and mice for stuck keys or damaged cables
  • All ports are clean and undamaged
  • Frayed power cords or blocked ventilation around the case
🧹 Cleaning Tools & Maintenance

Tools:

  • Compressed air for cleaning internal components
  • Lint-free cloth for screens and external surfaces
Tip: Internal cleaning should be done about once a year.

Software-Related Issues

Software faults relate to the operating system, drivers or applications. These issues often cause crashes, freezes or unexpected behaviour.

💀 Blue Screen of Death (BSOD)

What is it: A BSOD occurs when Windows encounters a critical error it cannot recover from.

Common Causes:

  • Corrupted system files
  • Incorrect or outdated drivers
  • Faulty RAM
  • Overheating hardware
  • Malware

Solutions:

  • Update drivers
  • Run Windows Update
  • Scan for malware
  • Check temperatures
  • Run CHKDSK
  • Test RAM
  • Replace faulty hardware if necessary
❄️ Application Not Responding

Problem: Applications may freeze and show a "Not Responding" status.

Common Causes:

  • Software bugs
  • Outdated versions
  • Slow internet
  • Faulty network cables
  • Low system resources

Solutions:

  • End the task and restart the application
  • Update the software
  • Check network connections
  • Reinstall the application
  • Clear temporary files
🦠 Malware Symptoms

Signs of Malware:

  • Slow performance
  • Unexpected pop-ups
  • Unknown programs starting automatically
  • Unusual system behaviour

Solutions:

  • Run antivirus scans
  • Remove detected threats
  • Restore from backups if needed
  • Document symptoms and actions taken
Warning: Use reputable antivirus software and keep it updated.

Printer-Related Issues

Printers commonly fail due to spooler errors, driver issues, connection problems or internal blockages.

📋 Print Spooler Errors

Problem: If the print spooler fails, no documents will print.

Solution:

  1. End the spoolsv.exe process
  2. Start the spooler again
  3. This clears stuck print jobs
🖨️ Print Test Page

Purpose: Printing a test page confirms whether:

  • The printer is detected
  • The driver is installed
  • The printer is responding

If Test Page Fails:

  • Reinstall drivers
  • Check connections
🔧 Printer Maintenance

Regular Maintenance Tasks:

  • Perform nozzle checks
  • Clean print heads
  • Align print heads
  • Remove debris inside the printer
Tip: Follow the maintenance steps in the printer's manual for specific instructions.
